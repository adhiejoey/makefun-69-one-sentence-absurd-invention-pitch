## The entry

`main.ts` writes a single sentence to `entry.txt` pitching **The Polite Sofa** —
a couch that, whenever it swallows your TV remote between its cushions,
clears its throat and spits it back onto the coffee table with a small
apologetic burp.

The annoyance is the remote vanishing into the sofa; the invention itself
is the joke, and the fix is silly yet weirdly plausible: a sofa with manners.

## Run

```sh
node main.ts
```

It reads `MAKEFUN_OUTPUT_DIR` (default `/output`), creates the directory if
needed, and writes `entry.txt` — one sentence, plain ASCII, no trailing
newline, 173 characters.
